%===============================================================================================
% PER-VARIANT ARRANGEMENT.
%===============================================================================================
% DIFFERENTIATION COMES FROM ARRANGEMENT, NOT ORNAMENT.
%
% What this file used to contain: six different \titleformat definitions (a full-width shaded
% grey bar, rules above and below the label, a vertical accent bar, a short one-sixth-width accent
% rule, small caps with no rule at all), four different bullet glyphs including one variant with
% no glyph at all, four different skills arrangements including two-column tables, six mastheads
% at three different sizes, and six different sets of rhythm lengths.
%
% Held beside the six reference resumes, every one of those was an invention. The references are
% recognisably ONE family precisely because they share a header treatment, a bullet, an entry
% shape and a rhythm; the differences between them are which sections they carry, in what order,
% and how a few blocks are arranged. A reviewer handed the old output could pick the generated
% document out of a stack of seven by its decoration alone, which is the definition of failing to
% belong to the family.
%
% So the visual grammar now lives entirely in _preamble.tex and is identical for all six, and each
% block below flips only arrangement switches. The switches, and where each is set:
%
%   variant   section order                          headline   masthead        coursework  skills
%   -------   ------------------------------------   --------   -------------   ---------   ------
%   A         Experience leads Skills                no         centred         3 columns   pipes
%   B         Skills lead; Certifications last       yes        centred + rule   inline     commas
%   C         Skills lead; Certifications mid        no         centred          inline     commas
%   D         C's order, tech stack on its own line  no         left + rule     3 columns    pipes
%   E         C's order                              yes        centred + rule  3 columns   commas
%   F         Certifications above Education         yes        left             inline      pipes
%
% Section order and the headline are set in the variant-*.tex files. The skills separator and the
% project tech-stack layout are set in VARIANT_STYLE in resumeGenerationService.js, because they
% decide what the CONTENT builder emits rather than how the template renders it. Everything else
% is below.
%
% EVERY AXIS FIRES FOR EVERY PROFILE, with one deliberate exception. Masthead alignment, the
% masthead rule, the section order and the skills separator all apply to any profile that has a
% name and skills, so no two variants can collapse onto each other because an optional field
% happened to be empty — which is how D once became byte-identical to C for any profile whose
% projects recorded no tech stack. The coursework switch is contingent by nature, since a profile
% with no coursework has no coursework section; it is a bonus axis, not a load-bearing one.
%
% CONTAINS NO CANDIDATE DATA.
%===============================================================================================

%%STYLE a%%
% ---- A: the plainest arrangement. Centred masthead with nothing under it, Experience ahead of
%         Skills, coursework in three columns. Its skills lines are pipe-separated.
% Every switch left at its preamble default; stated here as empty so the six blocks read alike.

%%STYLE b%%
% ---- B: centred masthead closed by a rule, carrying the positioning headline. Coursework runs as
%         a single inline list rather than three columns, and Certifications sits last.
%
% \hrule IN VERTICAL MODE, NOT \noindent\rule, AND WITH NOTHING BEFORE IT.
%
% The three ruled variants used "\vskip\resumeNameGap\noindent\rule{\linewidth}{0.4pt}". That
% \rule is a horizontal-mode box, so it starts a PARAGRAPH: the rule is 0.4pt tall, but its line
% is set a full \baselineskip below the contact line and the section header a full \baselineskip
% below that. The whitespace above "Summary" measured 25.9pt against 8.3pt above every other
% header — the void in the screenshot — and no spacing length could explain it, because no spacing
% length caused it.
%
% \hrule contributes its own 0.4pt and no leading. It also sets \prevdepth to ignore-depth, which
% suppresses the interline glue that would otherwise be computed from the contact line's
% fontawesome descenders, so the ruled variants land marginally TIGHTER than the unruled ones
% rather than looser: 9.3pt against 9.8pt, both against 7.8 to 8.3 elsewhere.
%
% The \vskip that used to precede the rule is gone. It cost 2pt that landed nowhere else in the
% document, and at 1:1 the rule reads better closing the masthead tightly than floating below it.
%
% Two things that look like improvements and are not, both measured: wrapping the rule in a
% zero-height \vbox, and resetting \prevdepth to 0 after the masthead. Both give the header box a
% \prevdepth of zero, which puts TeX in \baselineskip mode and ADDS a full 13.4pt — 21.3pt of
% whitespace above Summary, worse than the bug being fixed.
\renewcommand{\resumeHeaderRule}{\hrule height 0.4pt\relax}

% Coursework inline: one running list, separated by the same round bullet the document uses
% everywhere else. The separator LEADS each entry and is suppressed for the first, rather than
% trailing each entry — a trailing separator leaves a dangling glyph after the last course, and
% \unskip removes the space but not the glyph. \newif is plain TeX and needs no package.
\newif\ifresumecoursefirst
\renewcommand{\resumeCourseworkStart}{\begingroup\small\noindent\resumecoursefirsttrue}
\renewcommand{\resumeCourseItem}[1]{\ifresumecoursefirst\resumecoursefirstfalse\else\hspace{6pt}\resumebullet\hspace{6pt}\fi #1}
\renewcommand{\resumeCourseworkEnd}{\par\endgroup}

%%STYLE c%%
% ---- C: centred masthead with no rule and no headline — the quietest of the six — with skills
%         leading and coursework inline. Distinguished from A by its section order and from E by
%         carrying neither the headline nor the masthead rule.
\newif\ifresumecoursefirst
\renewcommand{\resumeCourseworkStart}{\begingroup\small\noindent\resumecoursefirsttrue}
\renewcommand{\resumeCourseItem}[1]{\ifresumecoursefirst\resumecoursefirstfalse\else\hspace{6pt}\resumebullet\hspace{6pt}\fi #1}
\renewcommand{\resumeCourseworkEnd}{\par\endgroup}

%%STYLE d%%
% ---- D: the only LEFT-ALIGNED masthead, closed by a rule. Coursework in three columns, skills
%         pipe-separated, and each project's tech stack on its own "Technologies:" line. The
%         alignment and the rule fire for every profile, so D cannot collapse onto C for a profile
%         that happens to record no tech stack — which is exactly what used to happen.
\renewcommand{\resumeNameAlign}{\raggedright}
\renewcommand{\resumeHeaderRule}{\hrule height 0.4pt\relax}

%%STYLE e%%
% ---- E: centred masthead closed by a rule, carrying the positioning headline, with C's section
%         order and three-column coursework. The rule is what keeps it distinct from C on a
%         profile with nothing to say in a headline, and its section order is what keeps it
%         distinct from B.
\renewcommand{\resumeHeaderRule}{\hrule height 0.4pt\relax}

%%STYLE f%%
% ---- F: left-aligned masthead with no rule, carrying the headline, Certifications credited above
%         Education, and coursework inline. The only variant that is both left-aligned and
%         unruled.
\renewcommand{\resumeNameAlign}{\raggedright}

\newif\ifresumecoursefirst
\renewcommand{\resumeCourseworkStart}{\begingroup\small\noindent\resumecoursefirsttrue}
\renewcommand{\resumeCourseItem}[1]{\ifresumecoursefirst\resumecoursefirstfalse\else\hspace{6pt}\resumebullet\hspace{6pt}\fi #1}
\renewcommand{\resumeCourseworkEnd}{\par\endgroup}
